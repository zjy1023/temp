# UX Review

用于每个页面完成时，按“每天使用”的标准检查。

## 检查清单

- [ ] 每个异步页面都有 loading / empty / error。
- [ ] 工作台有保存中 / 已保存 / 未保存 / 保存失败。
- [ ] 草稿自动保存，离开页面有未保存提示。
- [ ] 重叠时即时提示，片段高亮，保存/提交被阻止。
- [ ] 提交弹窗显示片段数和总时长；空提交二次确认。
- [ ] 提交后只读，时间轴和列表不可编辑。
- [ ] 键盘：Space、I/O、←/→、Delete、Ctrl+Z、Ctrl+S、Ctrl+Enter。
- [ ] 1024/1280/1440 宽度无溢出；桌面优先。
- [ ] 颜色对比度足够，状态不只靠颜色。
- [ ] 错误文案说明“发生了什么 + 怎么办”。

## 手工验收

- 打开工作台，拖动创建片段。
- 尝试制造重叠，确认被阻止。
- 刷新页面，确认草稿还在。
- 提交，确认只读。
