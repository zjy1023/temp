# 06 · UI / UX 规格

> 标注员每天都要使用这个界面，视觉与操作体验按产品标准执行。本文档把“好用、好看”拆成可执行规则。

## 1. 设计目标

1. **快**：标注员用键盘就能完成大部分操作，拖拽不卡。
2. **稳**：自动保存、冲突提示、离开提醒，不丢工作。
3. **清楚**：当前时间、片段、保存状态、提交状态一眼可见。
4. **一致**：登录、标注端、管理端使用同一套颜色、字号、间距和组件。
5. **专业**：像数据工具，不像演示 Demo；信息密度可以高，但层级要稳。

## 2. 视觉语言

### 2.1 颜色

| 用途 | 值 | 说明 |
|---|---|---|
| 页面背景 | `#F8FAFC` | 浅灰蓝 |
| 卡片/面板 | `#FFFFFF` | 主表面 |
| 次级表面 | `#F1F5F9` | 表头、代码块、嵌套区域 |
| 主文字 | `#0F172A` | 近黑 |
| 次文字 | `#64748B` | 说明、时间、辅助信息 |
| 边框 | `#E2E8F0` | 1px 分隔 |
| 主色 | `#0F766E` | teal 700；主按钮、选中、链接 |
| 主色 hover | `#115E59` | teal 800 |
| 主色浅底 | `#CCFBF1` | 选中背景、提示条 |
| 强调色 | `#F59E0B` | 当前片段、重点数据 |
| 危险 | `#DC2626` | 重叠冲突、错误、删除 |
| 成功 | `#16A34A` | 已保存、已提交 |
| 信息 | `#2563EB` | 链接、进行中 |

不使用渐变、玻璃拟态、重阴影；卡片阴影最多 `0 1px 2px rgba(15,23,42,.06)`。

### 2.2 片段颜色

| 状态 | 填充 | 边框 | 文字 |
|---|---|---|---|
| 普通片段 | `#99F6E4` | `#0F766E` | `#134E4A` |
| 选中片段 | `#FDE68A` | `#B45309` | `#78350F` |
| 冲突片段 | `#FECACA` | `#DC2626` | `#7F1D1D` |
| 只读已提交 | `#E2E8F0` | `#94A3B8` | `#334155` |

颜色不是唯一标识：冲突片段同时显示红色边框和感叹号图标；选中片段同时有加粗边框。

### 2.3 字体

- 正文：`Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`
- 数字/时间：`"JetBrains Mono", ui-monospace, Menlo, Consolas, monospace`
- 字号：12 / 13 / 14 / 16 / 20 / 24 / 32
- 行高：1.4–1.6
- 字重：400 正文，500 强调，600 标题；不要大面积 700。

### 2.4 间距与圆角

- 间距：4 / 8 / 12 / 16 / 24 / 32 / 40 / 48
- 圆角：6（小控件）、8（按钮/输入）、12（卡片/面板）、999（标签/头像）
- 页面左右留白：桌面 32；内容最大宽度 1440；工作台可全宽。

## 4. 页面规格

### 4.1 登录页

- 居中卡片，最大宽度 420px；左侧可放产品标识/一句说明，右侧表单；小屏单列。
- 标题“视频片段标注平台”，副标题“登录后领取任务并标注视频片段”。
- 字段：邮箱、密码；按钮“登录”；错误提示在表单上方。
- 演示账号面板（`DEMO_MODE=true` 时显示）：按角色列出账号，点击“填入”只填表单，不自动登录。
- 不显示注册、忘记密码。
- Loading：按钮转圈并禁用；错误不泄露账号是否存在。

### 4.2 标注员任务大厅

- 页头：标题“任务大厅”，副标题“本租户下可领取和进行中的任务”。
- Tabs：`可领取` / `进行中` / `已提交`，右侧显示数量。
- 卡片网格：1440 下 3 列，1024 下 2 列，小屏 1 列。
- 卡片内容：
  - 封面图（16:9，占位用渐变灰块/视频图标）
  - 标题（最多 2 行）
  - 视频时长、fps（如有）、已标注段数（进行中）
  - 状态 Badge
  - 主按钮：`领取任务` / `继续标注` / `查看提交`
- 空状态：图标 + “暂时没有可领取的任务” + “刷新”按钮。
- 领取中：按钮禁用 + “领取中…”。
- 领取失败 409：Toast“任务已被其他标注员领取”，并从列表移除。

### 4.3 标注工作台

布局（1440）：

```text
┌──────────────────────────────────────────────────────────────┐
│ 返回  任务标题  [状态]          保存状态    [提交任务]       │
├───────────────────────────────────┬──────────────────────────┤
│ 视频播放器（16:9）                │ 片段列表 340px           │
│                                   │ 当前时间 / 段数 / 总时长 │
│                                   │ [ + 添加片段 ]           │
│                                   │ 片段卡片 1               │
│                                   │ 片段卡片 2               │
├───────────────────────────────────┴──────────────────────────┤
│ 时间轴：刻度 + 片段条 + 播放头 + 缩放                         │
└──────────────────────────────────────────────────────────────┘
```

- 视频区背景 `#0F172A`，视频居中，最大高度 `60vh`。
- 右侧片段列表独立滚动，但页面不出现嵌套滚动条导致的滚动陷阱；列表高度固定为视频区高度。
- 时间轴在视频下方，全宽，高 120px（刻度 24 + 轨道 72 + 底部 24）。
- 提交按钮主色；只读状态替换为“已提交”Badge 和提交时间。

**播放器控制**：

- 播放/暂停、当前时间/总时长、音量、倍速 0.5/1/1.5/2、全屏。
- 点击视频切换播放/暂停；双击全屏。
- 时间显示 `mm:ss.SSS`；fps 已知时旁边显示帧号。
- 视频加载失败：显示“视频加载失败，请刷新重试”，并提供重试按钮。

**时间轴**：

- 刻度：根据缩放选择 1s/5s/10s/30s/1min；显示 `mm:ss`。
- 轨道：片段按 `start_ms/end_ms` 比例定位，最小可视宽度 4px。
- 播放头：1px 主色竖线 + 顶部小三角；播放时平滑移动。
- 空白处拖拽：创建片段；拖动时显示半透明预览和起止时间气泡。
- 片段左右把手：各 8px 可视宽度、12px 命中区域；拖动调整起止。
- 片段主体拖动：移动整段；移动时不能越过相邻片段或视频边界。
- 点击片段：选中；点击时间轴空白：跳转播放头。
- 重叠：拖动时实时 clamp；如果仍冲突，片段变红 + Toast“与已有片段重叠”。
- 缩放：`-` / `+` 按钮和 `Ctrl + 滚轮`；缩放后保持播放头可见。
- 最小片段长度：1 帧（fps 已知）或 100ms（未知）；小于最小值不创建。

**片段列表**：

- 每张卡片：序号、`开始 – 结束`、时长、跳转按钮、删除按钮。
- 起止时间可直接编辑：输入 `mm:ss.SSS` 或秒数；失焦校验；非法值恢复原值并提示。
- 选中卡片与时间轴片段双向高亮。
- 删除后 5 秒内可撤销（Toast 带“撤销”）。
- 空状态：“拖动时间轴选择片段，或按 I / O 打点”。

**键盘快捷键**：

| 按键 | 功能 |
|---|---|
| `Space` | 播放/暂停 |
| `I` | 设置当前时间为片段入点 |
| `O` | 设置当前时间为片段出点 |
| `←` / `→` | 前一帧/后一帧（fps 未知时 ±100ms） |
| `Shift + ←/→` | ±1 秒 |
| `Delete` / `Backspace` | 删除选中片段 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + S` | 立即保存草稿 |
| `Ctrl/Cmd + Enter` | 打开提交确认 |
| `Esc` | 取消拖拽/关闭弹窗 |

输入框聚焦时禁用全局快捷键，避免误触。

**保存与提交**：

- 自动保存：停止操作 800ms 后保存；显示 `保存中…` / `已保存` / `未保存`。
- 保存失败：显示红色“保存失败，点击重试”，不丢失本地状态。
- 提交前：如果有未保存修改，先保存；保存失败则阻止提交。
- 提交确认弹窗：片段数、总时长、空提交提示。
- 提交中：按钮禁用 + “提交中…”；重复提交 409 显示“任务已提交”。
- 提交成功：切换只读，Toast“提交成功”，显示提交时间和总时长。
- 只读：不能拖拽、不能编辑、不能删除；时间轴片段灰色。
- 页面离开：有未保存修改时 `beforeunload` 提示。

**冲突/异常状态**：

- 版本冲突：Modal“任务已在其他窗口修改”，按钮“刷新并加载最新版本”。
- 任务已被重分配/释放：Modal“任务已不属于你”，返回任务大厅。
- 会话过期：Modal“登录已过期”，保留本地草稿，登录后恢复。
- 视频加载失败/不支持编码：显示具体原因和“换 Chrome/Edge”建议。

### 4.4 管理员任务管理

- 页头：标题“任务管理”，右侧“发布任务”主按钮。
- 筛选：租户（平台管理员）、状态、关键词。
- 表格列：任务、租户、视频、状态、领取人、提交时间、有效时长、操作。
- 行操作：查看详情。
- 空状态：“还没有任务，发布第一个任务”。
- 发布任务：Modal 或独立页；步骤：
  1. 租户（平台管理员）/ 固定租户（租户管理员）
  2. 选择已有视频或上传新视频
  3. 标题、描述
  4. 发布
- 上传显示进度、文件名、大小；探测成功显示时长/fps/编码；失败显示原因。

### 4.5 管理员任务详情

- 页头：任务标题、状态 Badge、租户、返回。
- 左侧视频预览；右侧元数据：
  - 视频名、时长、fps、编码、大小
  - 领取人、领取时间
  - 提交时间、有效时长
- 下方：只读时间轴 + 片段表格（序号、起止、时长）。
- 未提交：显示“进行中”，可显示草稿段数；不显示草稿内容（避免管理员干扰）。
- 已提交：只读展示全部片段。
- 空提交：显示“未标注任何片段”，时长 0。

### 4.6 工作量统计

- 页头：标题“工作量统计”，副标题“按提交日汇总已提交任务的有效时长”。
- 筛选：日期范围（默认最近 7 天）、租户（平台管理员）、快捷“今天/最近7天/最近30天”。
- KPI 行：区间总时长、已提交任务数、活跃标注员数、今日时长。
- 柱状图：横轴日期，纵轴小时；0 也显示；Tooltip 显示 `X 小时 Y 分 / N 个任务`。
- 表格：日期、有效时长、任务数、标注员数。
- 时区说明：“按 Asia/Shanghai 归日”。
- 空状态：“所选区间没有已提交任务”。
- 导出 CSV（可选）：导出当前筛选结果，不受表格分页影响（本期无分页）。

### 4.7 视频库

- 页头：“视频库”，右侧“上传视频”。
- 表格/卡片：封面、文件名、时长、fps、编码、大小、上传时间、租户。
- 上传 Modal：拖拽/选择文件、进度、取消、探测结果。
- 不支持类型/超限/探测失败：明确错误，不留下半成品记录。
- 空状态：“还没有视频，上传一个演示视频”。

### 4.8 403 / 404

- 403：锁图标 + “没有权限访问这个页面” + 返回首页。
- 404：放大 404 + “页面或资源不存在” + 返回首页。
- 不显示堆栈、内部 ID、数据库信息。

## 5. 组件规范

| 组件 | 规则 |
|---|---|
| Button | 主/次/危险/幽灵四种；高度 36/40；loading 时禁用并保留宽度 |
| Input | 高 40；label 在上；错误文字在下；必填星号 |
| Select | 同 Input；租户切换用紧凑版 |
| Badge | 状态色 + 文字；不只靠颜色 |
| Card | 白底、1px 边框、12px 圆角、16–24 padding |
| Table | 表头浅灰；行 hover；数字右对齐；空状态 |
| Modal | 最大宽 560；标题、内容、底部按钮；Esc 关闭；焦点陷阱 |
| Toast | 右上角；成功/错误/信息；3–5 秒；可手动关闭 |
| Skeleton | 列表/详情加载；不要用整页 spinner |
| Tabs | 下划线或 pill；数量 Badge |
| Tooltip | 仅图标按钮使用；不承载关键信息 |

## 6. 状态清单

每个异步页面/组件必须考虑：

- Loading：骨架屏或局部 spinner。
- Empty：图标 + 一句说明 + 下一步动作。
- Error：错误原因 + 重试。
- Disabled：不可用原因（Tooltip 或说明）。
- Submitting：按钮 loading，防重复。
- Saved / Saving / Unsaved：工作台顶部。
- Conflict：版本冲突 Modal。
- Unauthorized：403/404 页面。
- Offline：Toast“网络已断开，恢复后重试”。

## 7. 响应式

| 宽度 | 行为 |
|---|---|
| ≥ 1440 | 三列任务卡；工作台右侧 340px |
| 1024–1439 | 两列任务卡；工作台右侧 300px；表格横向滚动 |
| 768–1023 | 单列；工作台右侧面板改为下方折叠；时间轴全宽 |
| < 768 | 可用但不优化；导航折叠；按钮全宽；时间轴可横向滚动 |

桌面优先；标注工作台在 1280×800 下必须完整可用。

## 8. 可访问性

- 所有交互元素可 Tab 到达，焦点环可见。
- 图标按钮有 `aria-label`；表单有 label。
- 颜色对比度 ≥ 4.5:1；状态同时用文字/图标。
- 键盘快捷键有说明入口（工作台“快捷键”按钮）。
- 动效尊重 `prefers-reduced-motion`；不做无限装饰动画。
- 错误提示用 `role="alert"`；Modal 焦点陷阱。

## 9. 文案规范

- 中文、短句、动词开头。
- 错误说“发生了什么 + 怎么办”，不写“系统错误”。
- 例：
  - “与已有片段重叠，请调整起止时间。”
  - “保存失败，请检查网络后重试。”
  - “任务已被其他标注员领取，请刷新列表。”
  - “没有标注任何片段，确认提交？提交后有效时长为 0。”
- 不出现内部错误码给普通用户；错误码放在详情或控制台。

## 10. 视觉验收清单

- [ ] 登录、任务大厅、工作台、管理端风格一致。
- [ ] 页面没有横向溢出；1024/1280/1440 检查。
- [ ] 所有按钮有 hover/focus/disabled/loading。
- [ ] 所有列表有 loading/empty/error。
- [ ] 时间轴片段不重叠显示错误；选中态明显。
- [ ] 长标题截断有 Tooltip 或换行，不遮挡按钮。
- [ ] 数字用等宽字体，时间对齐。
- [ ] 颜色对比度足够；不靠颜色单独表达状态。
- [ ] 没有无意义的渐变、阴影、装饰动画。
- [ ] 表单错误在字段附近，不只用 Toast。
