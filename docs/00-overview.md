# 00 · 产品范围与目标

## 1. 一句话

做一个多租户 Web 应用，替代“标注员把起止时间填进表格、管理员每天手工汇总”的视频片段标注流程。

## 2. 背景

数据团队需要标注员从机器人示教视频里标出有用片段。现状是手工填表、手工汇总，数字经常对不上。新系统要解决三件事：

1. 标注过程在视频上完成，起止时间可复核。
2. 有效时长由系统按统一口径计算，不靠人工汇总。
3. 多个租户的数据互相不可见，隔离由后端保证。

## 3. 角色

| 角色 | 能做什么 | 不能做什么 |
|---|---|---|
| 平台管理员 `PLATFORM_ADMIN` | 查看所有租户；上传视频；给任意租户发布任务；查看所有租户的每日统计；重新分配未提交任务 | 不能替标注员提交；不能修改已提交片段 |
| 租户管理员 `TENANT_ADMIN` | 管理本租户的视频、任务、统计；查看本租户已提交片段；重新分配本租户未提交任务 | 不能访问其他租户的任何数据 |
| 标注员 `ANNOTATOR` | 查看本租户可领取任务；独占领取；标注并保存草稿；提交；查看自己的提交 | 不能看其他租户；不能看其他人的草稿或提交；不能管理任务 |

## 4. 核心流程

1. 管理员上传视频，创建任务（标题、视频、租户），发布。
2. 标注员登录，看到本租户的可领取任务。
3. 标注员领取任务；任务被独占锁定。
4. 进入工作台：视频播放器 + 时间轴 + 片段列表。
5. 标注若干时间段；草稿自动保存；前端即时提示重叠。
6. 提交：服务端校验全量片段、重算总时长、记录提交时间、锁定任务。
7. 管理员查看该任务的片段列表；在统计页按天查看有效时长。

## 5. 输入与输出

### 输入

- 管理员发布任务时指定的视频和租户。
- 视频文件（MP4 / WebM，单文件最大 2 GB）。
- 标注员在视频上标出的若干时间段。

### 输出

- 每个已提交任务的时间段列表。
- 管理员页面上每天的有效时长。

## 6. 硬规则

| 规则 | 实现要求 | 验收方式 |
|---|---|---|
| 同一任务里的时间段不能重叠 | 以 assignment 为单位校验全量片段；半开区间 `[start, end)`；首尾相接允许；后端必须再校验一次 | 单测 + API 测试 + 前端拖拽测试 |
| 有效时长 = 已提交任务的片段长度之和 | 只统计 `SUBMITTED`；草稿、已释放、未领取都不计；提交时服务端重算并快照 | 单测 + 统计 API 测试 |
| 有效时长计入任务提交的那一天 | 用服务端生成的 `submitted_at`，按 `Asia/Shanghai` 归日；不是 `created_at`，不是视频内时间 | 时区边界测试 + 手工验收 |
| 租户数据隔离在后端完成 | 从 session 取 `tenant_id`；任务、视频、片段、统计、视频流全部校验；越权返回 404 | 跨租户 API 测试 + 视频流测试 |

补充的产品规则（详见 `01-decisions.md`）：

- 一个任务只能被一个标注员独占领取。
- 提交后锁定，不可修改。
- 允许空提交，但必须二次确认。
- 提交前允许保存草稿；草稿不计入统计。

## 7. 范围

### 本期要做

- 登录、角色、租户、seed 演示账号。
- 视频上传、服务端探测、封面、HTTP Range 播放。
- 任务创建、发布、领取、释放、任务列表。
- 标注工作台：播放器、时间轴、片段创建/编辑/删除、键盘操作、草稿自动保存、重叠提示。
- 提交、锁定、已提交片段列表。
- 管理员每日有效时长统计。
- 多租户隔离、后端权限校验。
- 单元测试、集成测试、E2E、500 MB 视频手工验收。
- Docker Compose 一键启动、本地 dev 模式、README、report.md。

### 本期不做

- 自助注册、找回密码、用户管理后台。
- 评论、标签分类、多人协作标注、实时同步。
- AI 自动分段、模型推理。
- 任务提交后的退回/重开。
- 一个任务多人领取或多份提交。
- 从 URL 导入视频（只支持本地上传）。
- 公网部署、HTTPS、CDN、对象存储。
- 移动端优先适配。
- 计费、审计日志、合规功能。

以上不做项不是“永远不会做”，而是本期不投入，避免挤占核心闭环和 UX 的时间。

## 8. 成功标准

按 README 从零启动后，能在 5 分钟内完成下面这条路径：

1. 用演示账号登录标注员，看到本租户任务。
2. 领取任务，打开视频，拖出两段，尝试制造重叠被阻止。
3. 提交任务，看到总时长。
4. 登录租户管理员，看到该任务的片段列表和当天有效时长。
5. 登录另一个租户的标注员，确认看不到前一个租户的任务和视频。
6. 平台管理员切换租户，看到两边数据。

同时满足：

- 四条硬规则都有自动化测试。
- 跨租户访问任务、视频、统计全部返回 404。
- 500 MB 视频能播放、拖动、跳转，服务端内存不随文件大小增长。
- 刷新页面不丢已保存草稿；提交后刷新仍是只读。
- 空库启动有 seed 数据；演示账号写在 README。
- `report.md` 写清决策、验证证据、rules/skills、未完成项。

## 9. 交付物

- 前后端源代码。
- `README.md`：技术栈、环境要求、启动命令、演示账号、测试命令、已知限制。
- 自动化测试代码。
- `docs/`：本目录下的方案文档。
- `report.md`：决策、验证证据与限制说明。
- 项目仓库链接（开发完成后推送到个人 GitHub）。
- 可选：截图、GIF、2 分钟演示视频。

## 10. 术语

| 术语 | 含义 |
|---|---|
| 租户 tenant | 数据隔离的单位；用户、视频、任务、统计都归属租户 |
| 视频 video | 管理员上传的 MP4/WebM 资产；带服务端探测的时长、fps、编码 |
| 任务 task | 一条待标注的视频任务；有标题、视频、租户、状态 |
| 领取 assignment | 标注员对任务的一次独占领取；草稿、片段、提交都挂在 assignment 上 |
| 片段 segment | 视频上的一个时间段 `[start_ms, end_ms)` |
| 草稿 draft | 已保存但未提交的片段集合；不计入有效时长 |
| 提交 submission | 标注员确认完成；记录 `submitted_at` 和总时长；之后锁定 |
| 有效时长 | 已提交 assignment 的所有片段长度之和 |
| 业务日 business day | 按 `Asia/Shanghai` 计算的日期，用于每日统计 |
| 平台管理员 | 跨租户的管理员，`tenant_id` 为空 |
| 租户管理员 | 只管理本租户的管理员 |
